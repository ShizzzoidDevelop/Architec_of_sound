# Architecture of Sound 🎵✨

**Мир, где звук становится движением в 3D пространстве**

---

## 🌌 Вдохновение

Этот проект родился из идеи, что каждый звук, каждое эхо и каждая вибрация в нашей жизни могут быть запечатлены в виде **движения в трехмерном пространстве**.  
Вместо сложных шейдеров и эффектов, мы создали простую и элегантную визуализацию, где каждая частота становится координатой.

> Что если **звук — это танец в пространстве**, а мы можем увидеть его траекторию?

---

## 🚀 Что такое *Architecture of Sound*

**Architecture of Sound** — это интерактивная веб-платформа, которая превращает звуки в движение в 3D пространстве.  
Каждый ритм, каждая частота становятся элементами простой, но выразительной визуализации:

- **Одна сфера** скачет по осям координат
- **Три оси** представляют разные частотные диапазоны
- **Следы** показывают путь движения
- **Квадратики** с данными появляются в моменты пиков

---

## ✨ Возможности

### 🎯 Простота и Элегантность
- Одна сфера вместо сложной геометрии
- Четкие оси координат с цветовой кодировкой
- Минималистичный дизайн без отвлекающих элементов

### 🎵 Музыкальная Геометрия
- **X ось (красная)** - низкие частоты (бас)
- **Y ось (зеленая)** - средние частоты  
- **Z ось (синяя)** - высокие частоты
- Анализ частот в реальном времени

### ✨ Визуальные Элементы
- **Следы** - сфера оставляет за собой путь движения
- **Квадратики с данными** - появляются при достижении пиков звука
- **Вращение пространства** - плавное движение для динамичности
- **Интерактивная камера** - управление мышкой для лучшего обзора

---

## 🛠️ Технологический алхимизм

- **Backend**: FastAPI (Python)  
- **Frontend**: HTML5, CSS3, ES6+  
- **3D Графика**: Three.js  
- **Аудио**: Web Audio API  
- **Рендеринг**: WebGL

## 🚀 Запуск

### Требования
- Python 3.8+
- Современный браузер с поддержкой WebGL

### Установка и запуск

1. **Клонировать репозиторий**
   ```bash
   git clone <repository-url>
   cd Architec_of_sound
   ```

2. **Установить зависимости**

   ```bash
   pip install fastapi uvicorn jinja2 python-multipart
   ```

3. **Запустить сервер**

   ```bash
   python main.py
   ```

4. **Открыть портал**

   ```
   http://localhost:8000
   ```

## 🌠 Как это работает

* **Сфера движется** по осям в зависимости от частот звука
* **Следы остаются** за сферой, показывая траекторию движения
* **Квадратики появляются** в моменты пиков с данными о звуке
* **Пространство вращается** для создания динамики
* **Камера управляется** мышкой для лучшего обзора
