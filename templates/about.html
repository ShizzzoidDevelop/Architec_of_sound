О Проекте

🎵 Вдохновение

Architecture of Sound родился из идеи, что каждый звук, каждое эхо и каждая вибрация в нашей жизни могут быть запечатлены в виде живого визуального полотна. Проект вдохновлён работами итальянского художника Lucio Arese, чьи аудио-визуальные эксперименты превращают музыку в архитектуру света и движения.

🌌 Философия

Что если мир — это симфония, а мы можем увидеть её очертания? Каждый ритм, каждая частота становятся элементами живого цифрового мира, где WebGL шейдеры оживляют скрытые паттерны, а Web Audio API анализирует дыхание звука.

🚀 Технологии

Проект построен на современных веб-технологиях: Three.js для 3D графики, WebGL шейдеры для сложных визуальных эффектов, Web Audio API для анализа звука и FastAPI для backend'а. Каждая технология выбрана для максимальной производительности и красоты.

🎨 Визуальные Эффекты

От фрактальных шумов и волновых деформаций до светящихся ореолов и цветовых искажений — каждый эффект создан для того, чтобы превратить звук в визуальное искусство. Система частиц реагирует на музыку, создавая цифровые звёзды, танцующие в такт.

🔮 Будущее

Проект постоянно развивается. В планах — шейдеры-стихии (огонь, вода, электричество), экспорт визуализаций в видео, пресеты для мгновенного переключения стиля и даже VR-поддержка для полного погружения в мир звуковых волн.
