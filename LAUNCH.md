# 🚀 Запуск Architecture of Sound

## Быстрый старт

### 1. Установка зависимостей
```bash
python3 -m pip install -r requirements.txt
```

### 2. Запуск проекта
```bash
python3 run.py
```

### 3. Открытие в браузере
```
http://localhost:8000
```

## 📋 Что получилось

✅ **Backend**: FastAPI сервер с поддержкой загрузки аудиофайлов  
✅ **Frontend**: Простой и элегантный интерфейс с 3D визуализацией  
✅ **Визуализация**: Одна сфера, скачущая по осям X, Y, Z  
✅ **Оси координат**: Цветовая кодировка для разных частотных диапазонов  
✅ **Следы**: Сфера оставляет за собой путь движения  
✅ **Квадратики с данными**: Появляются в моменты пиков звука

## 🎯 Как работает визуализация

### Оси координат
- **X ось (красная)** - Низкие частоты (бас)
- **Y ось (зеленая)** - Средние частоты
- **Z ось (синяя)** - Высокие частоты

### Движение сферы
- Сфера плавно перемещается по осям в зависимости от частот звука
- Позиция X зависит от низких частот
- Позиция Y зависит от средних частот
- Позиция Z зависит от высоких частот

### Визуальные элементы
- **Следы** - сфера оставляет за собой путь движения
- **Квадратики** - появляются при достижении пиков звука с данными о частотах
- **Вращение** - пространство плавно вращается для динамичности

## 🎮 Управление

- **Мышь** - вращение камеры для лучшего обзора
- **Колесо мыши** - приближение/отдаление
- **Правая кнопка мыши** - панорамирование

## 🚨 Возможные проблемы

### Микрофон недоступен
- Проект автоматически переключается в режим симуляции
- Визуализация работает без реального аудио

### WebGL не поддерживается
- Проверьте, что браузер поддерживает WebGL
- Обновите драйверы видеокарты

### Медленная работа
- Закройте другие ресурсоемкие приложения
- Уменьшите размер окна браузера
